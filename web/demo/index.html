Curso de demostración: Gestión de Incidentes y Problemas

Esta página simula el contenido de un curso de e-learning. El PDF de demo (scripts/demo_local.sh) trata sobre gestión de incidentes (página 1) y gestión de problemas (página 2) — sube ese PDF primero con ./scripts/demo_local.sh o POST /v1/documents, y luego pregúntale al tutor sobre ese contenido.

Esta página no es un LMS: existe únicamente para mostrar cómo el widget se integraría en el portal real de un curso.

Prueba una pregunta del contenido del curso (ej. "¿Qué es la gestión de incidentes?") y luego una fuera de alcance (ej. "¿Cómo se prepara una paella valenciana?") para ver el mensaje de evidencia insuficiente.
